## 模组介绍 / Description

**中文**

Monika Valley Story 是一个基于 Content Patcher 制作的模组。本模组将《Doki Doki Literature Club!》中的人气角色——文学部部长 Monika 带入了星露谷，使其成为一位完全可攻略的 NPC。

**English**

Monika Valley Story is a Content Patcher mod that brings Monika — the beloved Literature Club president from Doki Doki Literature Club! — into Stardew Valley as a fully romanceable NPC.

## 安装说明 / Installation

1. 安装 [SMAPI](https://smapi.io) 并用它启动一次游戏。 / Install [SMAPI](https://smapi.io) and run the game once with it.
2. 安装 [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)。 / Install [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915).
3. 下载本模组，把 `Monika Valley Story` 文件夹解压到 `Stardew Valley/Mods/` 目录下。 / Download this mod and extract the `Monika Valley Story` folder into your `Stardew Valley/Mods/` folder.
4. 通过 SMAPI 启动游戏，莫妮卡在巴士站等你！ / Launch the game via SMAPI — Monika will be waiting for you at the bus stop!
